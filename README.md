Este projeto foi desenvolvido em Python e utiliza um conjunto de dependências listadas no arquivo `requirements.txt`.

## 🚀 Como executar o projeto

### 0. Requisitos
- python >= 3.13.12
- Dependências listadas em requirements.txt

### 1. Clonar o repositório
```bash
git clone https://github.com/vichelly/techchallenge1-ovariopolicistico.git
cd techchallenge1-ovariopolicistico
```

### 2. Criar Ambiente
```bash
python -m venv venv
```

### 3. Instalar dependências
```bash
pip install -r requirements.txt
```

### 4. Instalar Extensões
- Instalar a extensão *Jupyter* no VS code

### 5. Executar projeto
- Abrir arquivo Treinamento01.ipynb
- Clicar no botão *'Executar Tudo'*

## Executar API
```bash
fastapi dev main.py 
```
